xyzzy 2025-04-20 20:13:53

Great essay. My issue with the romanticizing of lisp, smalltalk in particular is that, it takes of lots of real world usage to get programming languages right. These languages always thought of "games" or "performance" as an afterthought. Nor do these languages try to address the users problems. Lisp is next to useless for most tasks except simulation systems where it competes with Mathematica and MATLAB; MATLAB being much easier to use and performant.

The reason why C is successful is because they used it in the real world. Mundane practicality often beats theoretical brilliance.

Guyren Howe 2025-04-20 22:28:45

I’m not a LISP user but I know that LISP is not even close to “useless for most tasks”. It has libraries for just about anything.

My theory as to why LISP is not widely used is that it is too powerful — this is wonderful in the hands of a skilled user, but industrial at-scale code writing by large groups of programmers are better off with a more limited language like Java. It is easier to write bad code in LISP.
